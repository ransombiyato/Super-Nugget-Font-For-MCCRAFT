Psi is a mod about spell programming, inspired by Mahouka. Check out the [website](https://psi.vazkii.net/index.php) for more info.

This repository contains an unofficial Fabric port/adaptation of Psi for Minecraft 1.21.1.

Original Psi code and assets are by Vazkii and the Psi contributors. The Fabric port is maintained by Ícaro "RegulusXV".

This mod requires Fabric Loader, Fabric API, and [Patchouli](https://github.com/Vazkii/Patchouli). JEI support is optional.

Changes from upstream should be treated as Fabric port changes unless otherwise noted.
